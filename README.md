# Zing Guru

**Learn. Level Up. Lead.**  
An AI-driven, gamified learning ecosystem with real-world rewards — built to make education personalized, engaging, and inclusive.

---

## Problem Statement

Education today often lacks:
- **Personalization** – One-size-fits-all courses neglect individual learning pace.
- **Motivation** – Low engagement and lack of incentives cause drop-offs.
- **Accessibility** – Language barriers, disability needs, and cost issues block many learners.
- **Credibility** – Certificates lack real-world validation.

Zing Guru tackles these gaps by blending adaptive AI learning with blockchain-based rewards and all-access features. :contentReference[oaicite:1]{index=1}

## 🛠️ Tech Stack

- **Frontend/UI**: MERN stack, Tailwind CSS  
- **Backend/API**: FastAPI (Python)  
- **AI/ML**: TensorFlow  
- **Blockchain**: Ethereum + Polygon  
- **Prototyping/UI**: Streamlit, Chrome Extension  
- **Database**: MongoDB Atlas  
- **GenAI Integration**: For personalized learning and assistance
